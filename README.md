# masker — 流式聊天消息敏感词遮罩库

由消息接收层调用：词典存于本地 UTF-8 文件（每行一词），库按片段增量返回遮罩结果，
调用方负责拼接保存；原文不落盘。

## 调用方式

```go
d, err := masker.LoadDictionary("/path/to/dict.txt") // 加载一次，进程内复用
if err != nil { /* ... */ }

// 每条消息创建一个独立 Session，消息之间不会跨界匹配
s := d.NewSession()
var masked []byte
masked = append(masked, s.Submit(chunk1)...) // 片段可为空，可切在多字节码点内部
masked = append(masked, s.Submit(chunk2)...)
// ...
masked = append(masked, s.Finish()...)       // 结束消息，返回全部剩余内容
// masked 即完整遮罩结果，与对完整原文一次性遮罩逐字节一致
```

也可以用 `masker.NewDictionary([]string{...})` 直接从词条创建词典。

## 语义

- 匹配区分大小写，按 Unicode 码点精确比较，不做规范化。
- 所有词的所有出现位置都有效（自身重叠、词间重叠、相互包含）。
- 被至少一次命中覆盖的每个码点替换为一个 ASCII `*`；其余字节原样保留。
- 每次 `Submit` 返回后，已收到但未输出的完整码点数不超过「最长词码点数 − 1」，
  末尾不完整的 UTF-8 序列不计入。

## 实现要点

- Aho-Corasick 自动机，码点级转移，CSR 扁平存储；每位置只保留最长命中
  （同位置结束的词互为后缀，最长者覆盖其余），每码点均摊 O(1)。
- 覆盖判定用滑动窗口最小值（单调队列）：位置 p 被覆盖当且仅当窗口内
  存在命中区间起点 ≤ p。窗口大小 = 最长词码点数（≤1024）。
- 单条消息的额外存活内存为固定约 20 KiB（码点环 + 单调队列），
  不随累计消息长度增长。

## 测试

```sh
go test ./...          # 全部测试（含 64 MiB 性能实测，约 10 秒）
go test -short ./...   # 仅正确性测试
```

正确性：与独立暴力基准逐字节一致；覆盖重叠词、emoji、多字节码点被拆开、
长候选前缀最终失配（不提前遮罩）、同一消息不同分段输出一致、输出延迟上界。

本机实测（Apple Silicon，Go 1.27.1，64 MiB 输入）：

| 场景 | 耗时 |
|---|---|
| 5 万随机词（约 100 万码点），纯 ASCII | ~5.1 s |
| 词典 a^1..a^1024，输入全 a（每位置均命中） | ~0.9 s |
| 5 万词共享 1000 码点前缀、最终失配 | ~1.1 s |
| 会话处理 32 MiB 后堆存活增量 | ≤ 0（约 20 KiB 固定开销） |
